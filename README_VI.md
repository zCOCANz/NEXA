# Plan Pastel — GitHub Pages

1. Tạo repository mới `plan-pastel` trên GitHub, chọn Public.
2. Chọn Add file → Upload files.
3. Tải lên các file bên trong thư mục này: `index.html`, `manifest.json`, `icon.svg` (không chỉ tải ZIP).
4. Nhấn Commit changes.
5. Vào Settings → Pages → Build and deployment: Deploy from a branch; branch `main`, folder `/(root)`; Save.
6. Chờ trang Pages xuất bản, rồi mở URL được cung cấp.
7. Trên iPhone, mở URL bằng Safari → Share → Add to Home Screen → Add.

Lưu ý: GitHub Pages thường yêu cầu repository public trên GitHub Free và website được công khai. Bản hiện tại lưu dữ liệu trên từng trình duyệt bằng localStorage; chưa đồng bộ giữa thiết bị. Cần bổ sung backend có đăng nhập để đồng bộ an toàn. Không đưa dữ liệu cá nhân nhạy cảm vào repository.
